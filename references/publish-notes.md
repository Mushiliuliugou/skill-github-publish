# 发布参考

## 仓库布局

单 Skill：仓库根目录可包含 SKILL.md、README.md、LICENSE 和实际需要的资源。
多 Skill：README.md、LICENSE 放仓库根，技能放 skills/<skill-name>/SKILL.md；安装指令明确子目录。
不要只上传 ZIP 代替可浏览的源文件。GitHub 不会自动执行、注册或安装 Skill。

## README 最小内容

用途；兼容工具；依赖；按目标工具官方说明核实后的安装方式；示例输入输出；已知限制；许可说明。
发布前可用明显的仓库地址占位符，发布完成后替换并验证链接。
